# 高聚 · 个人简历网站

把简历 PDF 做成了一个单页网站，深色玻璃质感 + 滚动动效，纯静态、零依赖、可直接部署。

## 目录结构

```
resume-site/
├── index.html          页面结构（内容全部写在 HTML 里，无需 JS 也能看到内容）
├── css/style.css       样式 + 全部动画关键帧 + 响应式 + 打印样式
├── js/main.js          滚动动效、导航高亮、打字机等交互
├── assets/avatar.svg   头像占位图（线上版已移除证件照）
└── README.md
```

## 本地预览

**方式一：直接打开**

双击 `index.html` 即可，所有路径都是相对路径，`file://` 下功能完整。

**方式二：起个本地服务**（推荐，行为和线上一致）

```powershell
# 在 resume-site 目录下执行
python -m http.server 8788
# 然后浏览器打开 http://127.0.0.1:8788/
```

## 动效清单

- 顶部滚动进度条，随滚动实时增长
- 首屏三团极光色块缓慢漂浮 + 网格背景缓慢平移
- 姓名渐变文字流动 + 求职意向打字机轮播（逐字输入 / 删除）
- 证件照浮动呼吸 + 背后旋转光环 + 掠过式高光
- 全站滚动进入视口逐个淡入上浮（按 `data-delay` 错开）
- 工作经历时间轴渐变线随滚动生长，节点悬停放大发光
- 卡片悬停上浮、光晕、边框点亮；技能图标悬停旋转
- 导航吸顶、当前板块自动高亮 + 底部渐变指示条跟随
- 鼠标跟随的柔光（仅桌面精细指针设备）
- 返回顶部按钮渐入

## 响应式

- ≥1025px：信息四列、意向四列
- ≤1024px：两列
- ≤900px：导航收成汉堡菜单，首屏改为上下结构（照片在上）
- ≤620px：全部单列，字号与间距收紧

已适配 `prefers-reduced-motion`：系统开启「减弱动态效果」时会自动关闭动画，不影响内容阅读。

## 打印 / 导出 PDF

点首屏的「打印 / 存为 PDF」按钮，或直接 `Ctrl + P`。
打印样式会自动切换为白底深字、隐藏导航与装饰、压缩间距，便于生成一页纸简历。

## 内容修改

所有文字都在 `index.html` 里，按板块注释定位即可（`<!-- ===== 教育背景 ===== -->`）。
换头像直接替换 `assets/avatar.svg` 即可，建议 3:4 竖版。

## 部署

纯静态站点，把 `resume-site` 整个目录传上去就行：

- **GitHub Pages**：推到仓库后 Settings → Pages → 选分支目录
- **Vercel / Netlify**：直接拖拽目录，或将根目录设为 `resume-site`
